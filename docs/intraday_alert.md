# 日内 TopN 推送（趋势 / 超跌）

> **本文档为规范（Source of Truth）。**  
> 实现：`backend/src/market/intraday_alert.rs`、`intraday_push.rs`。  
> 仅使用真实行情（库内日 K + 盘中 Miana），无 Mock。

---

## 1. 目标

交易时段内每 **5 分钟** 各算一类 Top10，**分别推送两条通知**：

| 类型 | kind | 含义 |
|---|---|---|
| **上涨趋势** | `intraday_alert` | 相对大盘强势 + 五日结构 + 买点/量价比，偏续涨 |
| **超跌反弹** | `intraday_oversold` | 入选看多日超跌；排序看企稳/缩量，提高反弹概率 |

两类独立筛选，允许同一标的同时出现在两份列表（极少见）。

---

## 2. 调度

| 项 | 值 |
|---|---|
| 间隔 | 300 秒 |
| 时段 | 仅开市日连续竞价窗内重算、落库并推送；非交易时段不推 |
| 数据 | `load_market_window_hybrid(db, 11, …)`：近 10 个开市日 + 当日实时（超跌回看 10 日；趋势结构仍用近 5 日） |
| 原始行情 | `market_realtime_snapshot`（`(symbol, quote_ts)`） |
| 缓存 | `market_result_cache`：`kind=intraday_alert` 与 `kind=intraday_oversold`，主键 `(kind, date)` |
| 通道 | 各一条 `PushMessage { type: "notification", … }`；按各自 `condition_id` 与上一条 `payload` 去重 |

---

## 3. 共用常量

| 符号 | 值 | 含义 |
|---|---|---|
| `AMOUNT_MIN` | `3e7` | 成交额下限（元） |
| `PRESELECT_K` | `150` | 初筛上限 |
| `LIMIT_PCT` | `9.5` | 近涨停/近跌停近似阈值（买不进） |
| `SCORE_MIN` | `55` | 上涨趋势 Top10 最低分 |
| `SCORE_MIN_OVERSOLD` | `52` | 超跌 Top10 最低分 |
| `DELTA_MIN` | `1.2` | 相对大盘最少超额/弱势（百分点） |
| `RS_CAP` | `5.0` | RS 映射封顶 |
| `VP_LO / VP_HI` | `1.5e7 / 5e8` | 量价比 log 映射界（趋势侧） |
| `W_A / W_B / W_C` | `0.35 / 0.30 / 0.35` | 趋势：相对强度 / 五日 / 买点 |
| `WO_A / WO_B / WO_C` | `0.25 / 0.45 / 0.30` | 超跌：回撤质量 / **企稳** / 量能结构 |
| `DD_MIN` | `-8` | 超跌入选：至少回撤 8% |
| `OVERSOLD_LOOKBACK` | `10` | 超跌回看已收盘日数（峰值 / 坏趋势 / 量比） |
| `OVERSOLD_HIST_MIN` | `5` | 超跌最少已收盘日 K 根数 |
| `BROKEN_TREND_RN` | `-20` | 近 10 日几乎全阴且区间收益 ≤ 此值则剔除 |

大盘 \(R_{mkt}\)：有效样本等权均涨跌幅（**不含** \(R_i \ge LIMIT_PCT\) 或 \(R_i \le -LIMIT_PCT\)）。

基础有效票：成交额 ≥ `AMOUNT_MIN`、OHLC 有效、价 ≥ 2、涨跌幅有限。

---

## 3.1 盘中时段相位（上海时间）

连续竞价：**09:30–11:30**、**13:00–15:00**。依据学术开/收盘效应与成交量 U 型、论坛常见时段经验与交易心理，划分相位；**同一截面分在不同相位含义不同**，对层权重与门槛做微调。

| 相位 | 时钟 | 依据摘要 | 趋势侧重 | 超跌侧重 |
|---|---|---|---|---|
| `open` | 09:30–10:00 | 隔夜信息集中释放；知情/情绪交易密集；开盘噪声大 | 抬高量价/买点，压低纯 RS；门槛 +3 | 更重企稳，压低「深回撤」 |
| `am_active` | 10:00–10:30 | 早盘试盘后方向渐清；资金入场观察窗 | 接近基准，略提量价 | 企稳为主 |
| `am_mid` | 10:30–11:30 | 上午后半相对平稳 | 基准权重 | 基准 |
| `lunch` | 13:00–13:30 | 午后重开，假突破/情绪延续常见 | 略压 RS，提量价 | 提企稳、提缩量 |
| `pm_drive` | 13:30–14:00 | 午后主攻常见窗 | 基准偏强趋势 | 企稳 |
| `pm_turn` | 14:00–14:30 | 「两点半」变盘高发；游资急拉与反转并存 | 大幅提量价确认，压纯强度 | 大幅提企稳 |
| `close` | 14:30–15:00 | 收盘效应；调仓/避隔夜；尾盘急拉诱多风险高 | 压 RS，提买点质量；门槛 +5 | 企稳权最高；贴死低降权 |

非竞价时钟（不应推送）记为 `off`，权重退回基准、不加门槛。

相位只调整 **合成权重与最低分门槛**，不改过滤与层内公式。`payload.session_phase` 写入当前相位。

## 4. 上涨趋势（`intraday_alert`）

### 4.1 过滤

\(R_i > 0\)、\(R_i < LIMIT_PCT\)、\(RS_i = R_i - R_{mkt} \ge DELTA_MIN\)；按 \(RS\) 取前 `PRESELECT_K`。

### 4.2 得分（0–100）

\[
score = 0.35\,A + 0.30\,B + 0.35\,C
\]

**A — 相对强度**

\[
A = 100 \cdot \mathrm{clip}\big((RS_i - DELTA_MIN) / (RS_CAP - DELTA_MIN),\,0,\,1\big)
\]

\(pos=(P-L)/(H-L)>0.7\) 时 \(A \mathrel{+}= 5\)（上限 100）。

**B — 近 5 日 K**（已收盘，不含今日）

| 子项 | 权重 | 要点 |
|---|---|---|
| B1 五日收益 | 0.35 | \(R_{5d}\) ∈ `[2,12]` 满分 |
| B2 站上 MA5 | 0.25 | |
| B3 波动 | 0.20 | 振幅适中 |
| B4 量能 | 0.15 | 末日额/前均 ∈ `[1.1,2.5]` |
| B5 阳线抬高 | 0.05 | |

缺 5 日：\(B=40\)。

**C — 买点 + 量价比**

\[
VP_i = \mathrm{amount}_i / \max(R_i,\varepsilon),\quad
C5 = 100\cdot\mathrm{clip}\frac{\ln VP_i-\ln VP_{LO}}{\ln VP_{HI}-\ln VP_{LO}}
\]

| 子项 | 权重 | 要点 |
|---|---|---|
| C1 剩余空间 | 0.20 | \(h=LIMIT_PCT-R_i\)；\(C1=100\cdot\mathrm{clip}((h-0.5)/5)\) |
| C2 回流区 | 0.20 | \(pos\in[0.35,0.65]\)→100；邻域 70；\(pos>0.9\)→35；其余 50 |
| C3 回吐 | 0.15 | \(giveback=(H-P)/P_{prev}\times100\)；&lt;1→100；&lt;3 线性降；否则 30 |
| C4 绝对流动性 | 0.10 | \(C4=100\cdot\mathrm{clip}((\ln amount-\ln AMOUNT_MIN)/3)\) |
| **C5 量价比** | **0.35** | 同上 \(C5\)；同涨幅成交额越大越好 |

排序：`score` ↓，`RS` ↓，`amount` ↓；取前 10 且 \(score\ge SCORE_MIN\)。

推送标题：`上涨趋势 Top{N}`；系统条件名「上涨趋势股」。

## 5. 超跌反弹（`intraday_oversold`）

原则：**入选看超跌，排序看企稳**。回撤只做门槛与轻权重质量分，主分给止跌/缩量，避免「越惨越高分」。

### 5.1 回撤定义

取近最多 **10** 个已收盘日的最高价 \(H_{peak}=\max high\)，今日价 \(P\)：

\[
DD_i = (P / H_{peak} - 1)\times 100
\quad\text{（百分点，通常为负）}
\]

### 5.2 过滤（入选）

- 当日 \(R_i < 0\) 且 \(R_i > -LIMIT_PCT\)（下跌但非近跌停）  
- 至少 5 根历史日 K，且 \(DD_i \le DD_{MIN}\)（至少回撤 8%）  
- **剔除趋势坏票**：近最多 10 日几乎全阴（上涨日 ≤ 1）且区间收益 ≤ −20%  
- 按 \(|DD|\) 取前 `PRESELECT_K` 再打分  

### 5.3 得分

\[
score = 0.25\,A + 0.45\,B + 0.30\,C
\]

**A — 回撤质量（0.25，非越深越高）**

\(|DD|\) 甜区约 `[10, 20]` 高分；刚过门槛（~8%）偏低；极端深跌（>~20%→28%）降分（坏趋势风险）。

**B — 企稳（主，0.45）**

| 子项 | 权重 | 要点 |
|---|---|---|
| 下影/收回 | 0.25 | \((P-L)/(H-L)\) 越高越好（收近全日高，锤头） |
| 日内位置 | 0.20 | \(pos\in[0.35,0.75]\) 佳；贴死低或冲太高降 |
| 相对大盘 | 0.20 | \(RS=R_i-R_{mkt}\) 越接近 0 越好（止跌相对市场） |
| 未创新低 | 0.20 | 今日低 ≥ 昨低 满分；略破降；深破低 |
| 跌幅温和 | 0.15 | \(|R_i|\) 小优于暴跌 |

**C — 量能结构（0.30）**

今日额 / 昨额：缩量（≤0.7）高分；继续大幅放量砸盘低分。  
若昨日已下跌且今日缩量，额外加分（出清后安静）。

排序：`score` ↓，企稳层 \(B\) ↓，`amount` ↓；取前 10 且 \(score\ge SCORE_MIN_OVERSOLD\)。

推送标题：`超跌反弹 Top{N}`；系统条件名「超跌反弹股」。  
`items[].drawdown_pct` 写入 \(DD_i\)；`reason` 含 `DD=… stab=…`。

## 6. 推送载荷

每条通知：

- `payload.kind`：`intraday_alert` 或 `intraday_oversold`  
- `payload`：`date` / `r_mkt` / `sample_size` / `candidate_size` / `session_phase` / `items[]`  
- App：解析两类 payload；默认收起前 3 名，展开全部并标已读
